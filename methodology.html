팀 점수는 조건부 적합도입니다

최종 1–9점은 입력한 맵·구역·양 팀에 대한 비교 기준입니다. 계산 항목은 중립 5의 0–10 척도로 평가하고, 가중 평균과 중립의 차이를 2.5배 확대해 1–9로 제한합니다. 실제 승리 확률이나 영웅의 절대 성능이 아닙니다. 상성 30%, 맵 20%, 시너지 25%, 제약 대응 10%, 통계 15%의 가중 평균이며, 통계가 없는 범위는 통계 항목을 빼고 합계 85로 나눕니다. 대응 근거가 없는 항목은 중립 5에서 시작합니다.

분석 화면의 ‘팀 점수 · 계산과 실행 조건’을 펼치면 항목별 가산·감점, 계산식, 근거와 한계를 확인할 수 있습니다. 카운터 목록에 없다는 이유만으로 높은 점수를 주지 않습니다. 실제 위치·쿨타임·궁극기·숙련도·소통은 관측하지 않으므로 실행 조건을 함께 읽어 주세요.

공개된 점수 계산식

R = (상성×30 + 맵×20 + 시너지×25 + 제약대응×10 + 통계×15) ÷ 100
최종 점수 = 소수 1자리 반올림(최솟값 1, 최댓값 9로 제한한 [5 + (R − 5) × 2.5])

통계가 없으면 해당 항목을 빼고 85로 나눕니다. R=3.4는 1점, R=5는 5점, R=6.6은 9점입니다. 후보 목록의 순위나 최저·최고 영웅에 따라 점수를 강제로 늘리지 않습니다. 점수 상한·하한에서 같은 점수가 나온 후보는 원래 가중 평균으로 추가 정렬합니다.

개인 점수의 맵 항목은 후보의 사거리와 합류 도구, 구간 조건을 평가합니다. 시너지는 그 후보와 아군의 연결만 반영하며, 이미 있는 아군끼리의 보너스를 모든 후보에게 복제하지 않습니다. 상대 대응과 카운터 제약은 별도 항목이며 등록된 관계가 없으면 중립을 유지합니다.

그래프의 여섯 지표

기동성은 합류·이탈, 유지력은 치유 기반과 보호, 받아치기는 상대 진입 저지와 아군 보호, 사이드는 다른 각도의 압박과 복귀, 사거리는 유효 거리의 도구, 변수는 제어·증폭·순간 압박 기회를 보여 줍니다. 각 축에서 영웅별 기여와 태그 근거를 펼쳐 볼 수 있습니다. 개인 생존기와 아군 치유를 같은 것으로 계산하지 않습니다.

축별 수치와 가중치는 공개된 편집 규칙입니다. 실측 피해량·치유량이나 검증된 승률 모델은 아닙니다. 궁극기가 현재 준비됐다는 뜻도 아니며, 그래프 면적이 크다고 항상 더 좋은 조합이라는 뜻도 아닙니다.

영웅의 도구와 구간 조건을 연결합니다

54명 각각의 강점·약점·실행 조건을 저장합니다. 기본 기술, 궁극기, 선택 특전과 미확인 기능을 구분합니다. 프로필에 설명이 있는 것과 점수에 가감한 것은 다르며, 실제 가감한 도구는 추천 상세의 ‘이번 조건에서 반영된 특성’에 항목·수치·조건·출처와 함께 표시합니다.

공수와 구간 ID가 정확히 맞는 30개 전장 프로필에서는 시야·고지 접근·엄폐·우회·폭·코너·노출 가운데 실제 근거가 있는 항목을 함께 평가합니다. 미확인 지형은 숫자로 채우지 않습니다. 서킷 로얄 1·2·3구간을 모두 같은 긴 시야로 계산하지 않습니다. 135개 구간은 근거 검토 대기이며 기존 지형 분류를 사용하는 임시 평가라고 표시합니다. 검토된 지형 기록도 최신 패치의 게임 화면을 재검증한 자료는 아닙니다.

로드호그의 자기 회복은 동료 치유 부담을 덜 가능성을 보고, 치유 차단의 제약은 탱커 압력에서 한 번만 계산합니다. 갈고리는 적중·범위·엄폐·동료 후속 공격을 요구하며, 같은 원인을 여러 항목에 반복 가산하지 않습니다. 실제 위치·쿨타임·특전 선택은 관측되지 않으므로 도구 보유를 실행 성공으로 단정하지 않습니다.

맵·티어의 직접 승률과 픽률

일차 자료는 Blizzard 공식 영웅 통계입니다. 웹 빌드 시 54명·31개 맵, PC·아시아·역할 고정의 287개 범위·15,498개 영웅 레코드를 확보했습니다. 이 레코드 수는 경기 표본 수가 아닙니다. 맵×티어 직접 범위는 277개이며 2개 범위는 네트워크 응답을 확보하지 못해 미확보로 기록합니다. 경기 수·승패·미러 비율·집계일·패치 ID는 원본에서 미공개입니다.

공개 통계 파일은 웹 코드와 별도로 6시간마다 수집합니다. 사이트는 접속 시·다시 보이는 시점·30분마다 같은 출처의 공개 갱신본을 확인하며, 영웅 목록·범위·수치 검증에 실패하면 저장 통계를 유지합니다. 전체 맵·티어를 다시 확인하는 중 일부 응답이 시간 초과되면 그 범위의 이전 관측값과 수집 시각을 보존하고, 확보한 적 없는 범위는 미확보로 남깁니다. 공식 응답이 거부되면 자동 수집을 중단합니다. 화면의 범위별 수집 시각은 원본 집계 시각과 다릅니다. 현재 공개 통계 파일 →

선택 맵×티어의 직접 공식 표시값을 먼저 사용합니다. 미확보 범위에서만 같은 원본의 티어 전체 맵·전체 티어 맵 경향으로 제한된 교차 추정 또는 대체 범위를 표시합니다. 세 승률을 중복 가산하지 않습니다. 픽률은 경기 수가 아니며 공개되지 않은 미러 비율로 원본 승률을 역산하지 않습니다. 실제0%와100%는 보존하고 원본 -1 결측 표식은 미확인으로 처리합니다. 원본에도 남아 있는0/100%는 표본 미공개 안내를 표시합니다.

탱커의 복수 카운터와 후속

같은 큰 제약 하나만 선택하던 방식 대신, 확인된 기본 제어·회복 차단·집중 화력·방어 우회·출력 제약·대상 보호의 독립적인 잠재 압력을 누적합니다. 같은 적·같은 도구의 겹친 영향은 중복하지 않고, 반복 기제는 영향도를 줄여 원인별1.8·전체4로 제한합니다. 아군의 확인된 정화·구출·방벽과 탱커 자신의 실제 방어 도구가 유효한 창에서만 완화합니다. 공격 방식과 보호 대상을 구분하고, 미확인을 면역이나 도구 부재로 바꾸지 않습니다.

상대의 카운터 도구가 후속 공격과 연결될 때 강해지고, 탱커 자신이 상대에게 만드는 기회는 자신의 도구에 한정합니다. 아군 다른 영웅의 독립적인 상성 보너스를 빌리지 않습니다. 실제 위치·적중·쿨타임은 관측하지 않은 조건부 모델입니다.

현재 패치의 역할과 도구

2026년10월7일 한국 패치(영문10월6일)의 로드호그·솜브라 리워크와 독트린 정식 출시, 새 호위 맵 그림스뵈튼을 반영했습니다. 삭제된 기본 기술을 전제로 하는 옛 운영 지침은 보류하고, 스타디움·궁극기·선택 특전은 일반 기본 도구와 구분합니다. 수치 변경을 임의의 추천 보너스로 환산하지 않습니다. 패치 검토와 통계의 실제 원본 집계 패치 확인은 다릅니다.

전술 원칙과 영상

다섯 목록의 고유 영상 332편 중 첫 세 목록 전체와 나머지 목록의 조합 관련 영상을 합쳐 235편을 선정했습니다. 확보된 자막 232편을 끝까지 의미 검토하여 조건부 원칙 424개를 정리했습니다. 자막이 없거나 접근되지 않은 3편은 미검토이며, 수동 맥락 확인이 필요한 원칙 65개는 자동 적용에서 제외합니다.

영상 목록 수집, 자막 확보, 자막의 의미 검토, 화면 검증을 구분합니다. 검토한 원칙은 ‘왜’, ‘플레이 방법’, ‘필요 조건’, ‘예외와 피할 운영’, 영상 시간과 게시일을 함께 저장합니다. 조합에 등장하는 영웅 이름만으로 보너스 점수를 더하지 않습니다. 오래된 패치의 수치·특정 시즌 서열·과거 인원수의 조합은 현재 일반 원칙과 분리합니다.

현재 반영은 제공된 자막의 의미 검토이며, 영상 화면 전체의 위치와 수치를 확인했다는 뜻은 아닙니다. 조건이 맞는 원칙은 추천 상세에서 출처의 해당 시간으로 연결합니다. 자료를 읽는 것은 모델 가중치를 재학습했다는 의미가 아닙니다.

5대5 역할 고정과 공방 없는 모드

아군 궁합은 돌격 1명·공격 2명·지원 2명의 역할 고정을 기준으로 검증합니다. 돌격 영웅에게 다른 돌격 영웅을 아군 궁합으로 추천하지 않으며, 현재 패치의 역할을 사용합니다. 쟁탈·밀기·플래시포인트는 공격·수비 선택 없이 구역 조건으로 한 번 추천합니다. 과거의 공격용·방어용 지형 규칙을 같은 거점에 따로 적용해 목록이 달라졌던 문제를 제거했습니다. 호위·혼합만 실제 공격·수비 구분을 유지합니다.

공식 자료로 교체한 정보와 남아 있는 편집 근거

OWTICS 자료는 비교용입니다. 추천 점수의 승률·픽률·밴률은 Blizzard 공식 통계 응답을 사용합니다. 지역·기간·티어가 맞지 않는 외부 수치를 합치거나 독립 표본으로 중복 계산하지 않습니다.

영웅 이름·역할·기술·특전 설명은 Blizzard 공식 영웅 페이지를 직접 수집합니다. 맵 ID·이름도 공식 통계 목록으로 대조합니다. 공식 HTML 수집과 공식 웹의 JSON 응답은 정식 개발자 API의 호환성 보장과 구분합니다. 공식 페이지에 없는 생명력·방어력·보호막과 기술 계수는 기존 출처·검토 상태를 보존하며, 공식에서 제공한 값으로 바꾸어 표시하지 않습니다. 한국 공식 패치노트와 최신 Blizzard 패치도 구별해 기록합니다.

영웅 궁합·상성의 운영 이유, 거점 지형과 진입 동선은 공식 통계에 없는 전술 편집 자료입니다. 기존 위키·영상 근거와 검토 상태를 표시합니다. 공식 목록에 포함된 맵이라고 해서 실시간 경쟁전 로테이션을 확인했다고 해석하지 않습니다. 공개 프로필 검색은 공식 웹의 교차 출처 호출 제한 때문에 현재 OverFast 중계가 남아 있으며 공식 프로필 링크도 제공합니다. 공식 자료 교체 범위와 제한 →

전적 검색과 최근 경기

전적은 Blizzard 공개 프로필을 제공하는 OverFast API로 조회합니다. 이름 검색 결과의 현재 계정 ID 형식을 지원하며, PC·콘솔 및 경쟁전·빠른 대전을 구분합니다. 비공개 프로필은 열 수 없습니다. 현재 공개 API는 최근 개별 경기의 시간·맵·결과·점수판을 제공하지 않습니다. 누적 전적을 최근 경기라고 표시하거나 보이지 않는 경기 정보를 생성하지 않습니다.
