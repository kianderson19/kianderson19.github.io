현재 수집·처리하는 정보

Johap 웹사이트에는 자체 회원가입이나 자체 사용자 데이터베이스가 없습니다. 선택한 영웅·맵·구역·설정과 화면 테마는 사용자의 브라우저 저장소(localStorage)에 저장될 수 있습니다. 이 정보는 같은 기기의 사용 편의를 위한 것이며 Johap 서버로 전송되지 않습니다.

스크린샷과 데스크톱 캡처

불러온 이미지와 선택한 캡처 화면은 기기 안에서 영웅·맵 인식에 사용합니다. Johap은 해당 이미지를 분석 목적으로 외부 AI나 자체 서버에 업로드하지 않습니다. 데스크톱에서는 사용자가 선택한 화면·창과 캡처 시작 설정을 사용합니다. 캡처를 중지하거나 앱을 종료하면 진행 중인 캡처 작업도 중단됩니다. 직접 내보낸 진단 자료는 내용을 확인한 뒤 공유해 주세요.

전적 검색과 외부 서비스

전적 검색에 입력한 배틀태그는 검색을 제공하는 OverFast API로 전달됩니다. 전적은 공개 프로필의 정보에 따라 표시되며, 비공개 프로필은 조회가 제한될 수 있습니다. 외부 요청을 받는 제공자는 IP 주소와 요청 정보를 자체 정책에 따라 처리할 수 있습니다. OverFast · GitHub 개인정보 안내

호스팅과 문의

이 사이트는 GitHub Pages에서 제공됩니다. GitHub는 서비스 운영을 위해 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 공개 문의에 작성한 내용은 GitHub에서 다른 방문자도 볼 수 있으므로 민감한 정보를 남기지 마세요. GitHub 계정 및 문의 정보의 관리는 해당 서비스의 기능과 정책을 따릅니다.

광고와 쿠키

현재 배포에는 광고 코드를 설치하지 않았으며, Johap이 광고 추적 쿠키나 분석 추적기를 추가하지 않습니다. Google AdSense를 도입할 경우 광고·쿠키·동의 처리의 내용과 관련 제공자를 이 방침에 반영한 뒤 적용합니다. Google의 심사 승인과 필요한 이용자 동의 없이 광고가 이미 운영 중인 것처럼 표시하지 않습니다.
