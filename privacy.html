JOHAP은 팀 조합과 영웅 선택을 돕는 도구입니다. 별도 회원가입이나 자체 사용자 계정은 없습니다. 조합 분석과 점수판 사진 인식은 기기 안에서 처리합니다. 공개 자료 갱신, 선택한 전적 검색, 웹 방문·성능 집계와 개발용 광고 시험에는 아래에 설명한 외부 서비스 연결이 사용됩니다.

조합·설정과 보관함

선택한 영웅·맵·경기 조건·평가 설정·테마와 현재 조합은 사용 중인 브라우저 또는 앱의 로컬 저장소에 보관됩니다. 조합 보관함에는 사용자가 정한 제목·저장 시각·조합을 최대 50개까지 저장할 수 있습니다. 이 저장 기능은 JOHAP 계정이나 자체 서버에 조합을 동기화하지 않습니다.

저장 정보는 사용자가 삭제하거나 브라우저·운영체제의 앱/사이트 데이터 삭제 기능으로 제거할 때까지 기기에 남을 수 있습니다. 기기 변경·앱 삭제·사이트 데이터 삭제 시 자동 복구를 제공하지 않으므로 필요한 조합은 공유 링크로 따로 보관해 주세요.

사진 선택·카메라와 인식

점수판 사진은 사용자가 직접 선택하거나 촬영한 경우에만 불러옵니다. 사진은 기기 안에서 영웅·맵 등을 인식하고 결과를 확인·수정하는 데 사용합니다. JOHAP은 이 사진을 외부 AI 또는 자체 분석 서버에 업로드하지 않으며, 조합 보관함에도 사진 자체를 저장하지 않습니다.

iPhone·iPad에서는 시스템 사진 선택기와 사용자가 승인한 카메라를 사용합니다. Android에서는 시스템 사진 선택기 또는 외부 카메라 앱을 엽니다. Android 촬영 과정의 임시 파일은 정상 처리 완료 또는 취소 시 삭제합니다. 원본 사진의 앨범 보관 여부는 사용한 카메라·사진 앱의 설정을 따릅니다.

사진·카메라 기능을 취소하거나 접근을 허용하지 않아도 영웅과 경기 조건을 직접 입력해 조합을 분석할 수 있습니다. 카메라 권한은 운영체제의 JOHAP 권한 설정에서 변경할 수 있습니다. 선택한 사진의 원본을 지우려면 사진을 보관하는 앱에서 직접 삭제해야 합니다.

데스크톱 화면 캡처 기능을 사용하는 경우에는 사용자가 고른 화면·창만 분석에 사용합니다. 캡처 중지 또는 앱 종료 시 진행 중인 캡처도 중단됩니다. 사용자가 직접 내보내는 진단 자료는 내용을 확인한 뒤 공유해 주세요.

조합 링크 공유

공유 버튼은 맵·영웅·밴·포지션·경기/평가 조건을 담은 링크를 만들고, 사용자가 선택한 공유 앱이나 클립보드로 전달합니다. 사진·배틀태그·보관함 제목은 조합 링크에 포함하지 않습니다.

링크를 받은 사람은 링크에 담긴 조합을 확인할 수 있습니다. 공유한 앱·메신저의 메시지 보관과 전달 처리는 해당 서비스 정책을 따릅니다.

공개 자료 갱신과 전적 검색

앱은 최신 패치·통계 자료를 확인하기 위해 GitHub Pages의 공개 HTTPS 자료에 연결합니다. 웹사이트는 현재 접속한 JOHAP 주소의 공개 자료를 사용합니다. 갱신이 실패하면 마지막으로 검증한 자료와 기기에 포함된 자료로 분석을 이어갑니다.

전적 검색 기능을 사용하면 입력한 이름·배틀태그와 선택한 공개 선수 프로필 요청이 OverFast API로 전달됩니다. 비공개 프로필은 조회가 제한될 수 있습니다. 이 기능은 넓은 화면 등 전적 검색이 제공되는 화면에서 선택적으로 사용할 수 있습니다.

이러한 외부 요청을 받는 서비스에는 IP 주소·요청 주소·요청 시각 등 네트워크 정보가 전달될 수 있습니다. 외부 제공자가 처리하는 자료의 보존과 삭제는 해당 서비스 정책 및 문의 절차를 따릅니다. JOHAP의 로컬 삭제 버튼이 외부 제공자의 로그를 삭제하지는 않습니다.

광고

웹사이트: 현재 Google AdSense 소유권 확인 메타 태그와 ads.txt를 사용합니다. 광고 공간은 마련되어 있지만, 광고 송출 스크립트는 연결하지 않았습니다. 광고 운영과 별도로 Cloudflare Web Analytics를 통한 방문·성능 집계가 제공되며, 그 내용은 아래 “웹 방문·성능 집계와 호스팅”을 참고해 주세요.

현재 iPhone·iPad 앱: Google 광고 SDK를 포함하지만 운영 광고와 광고 동의 요청은 비활성화되어 있습니다. 광고 개인정보 설정을 누르면 현재 광고가 비활성화되어 있다는 안내를 표시합니다. 광고를 실제 제공하는 버전으로 바꿀 때 이 방침과 필요한 동의·설정 기능을 함께 갱신합니다.

스토어 제출용 Android 앱: 현재 광고와 광고 동의 요청을 비활성화했습니다. 광고 개인정보 설정을 누르면 현재 버전에서 광고를 사용하지 않는다는 안내를 표시합니다. 광고를 제공하는 버전으로 바꿀 때 이 방침과 필요한 동의·설정 기능을 함께 갱신합니다.

별도 개발 시험용 Android 앱: 개발 검수에만 Google Mobile Ads의 공식 테스트 배너와 User Messaging Platform을 사용할 수 있습니다. 테스트 배너는 광고 수익 발생이나 운영 광고 승인을 의미하지 않습니다. 이 개발용 버전에서는 필요한 지역의 동의 화면 및 광고 개인정보 옵션을 통해 설정을 확인할 수 있습니다.

광고가 실행되는 Android 개발용 버전의 SDK는 광고·측정·분석·부정행위 방지를 위해 IP 주소와 그로부터 유추한 대략적 위치, 앱/광고 상호작용, 성능·진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 수집·공유할 수 있습니다. Google은 광고 SDK 전송에 TLS 암호화를 사용한다고 안내합니다. 시험 광고 또는 비개인화 광고도 데이터 처리가 전혀 없다는 뜻은 아닙니다. 현재 광고가 비활성인 Release 준비본과 구분해 안내합니다. Google Android 광고 데이터 안내 · Google 개인정보처리방침

Google 등 외부 제공자의 보존·삭제·개인정보 권리 행사는 해당 제공자의 정책과 계정/기기 설정을 따릅니다. Android 광고 ID는 기기의 Google 광고 관련 설정에서 초기화하거나 삭제할 수 있습니다. 운영 광고 제공 여부와 필요한 동의 기능은 실제 앱 버전에 맞춰 이 페이지에 안내합니다.

웹 방문·성능 집계와 호스팅

웹사이트는 Cloudflare Web Analytics를 사용해 방문·페이지뷰 수와 페이지 로딩 시간·Core Web Vitals 등 성능 정보를 집계합니다. 페이지/호스트·유입 주소, 기기 유형·브라우저·운영체제·국가 등 범주로 사이트 사용과 성능을 확인할 수 있습니다. 이 집계는 페이지의 Cloudflare beacon을 통해 전송됩니다. Cloudflare 수집 방식 · 집계 항목

Cloudflare는 Web Analytics가 이용 통계 집계에 쿠키·localStorage를 사용하지 않고, 분석 표시를 위해 개인별 지문을 만들거나 고객 사이트 간 개별 이용자를 추적하지 않는다고 설명합니다. 이 안내는 사이트 이용 집계가 전혀 없다는 뜻이 아니며, 호스팅·보안 요청 처리는 별도입니다. Cloudflare Web Analytics 안내

JOHAP 웹사이트는 Cloudflare와 GitHub Pages를 통해 제공됩니다. 방문 주소와 공개 자료 요청에 따라 해당 제공자가 IP 주소·접속/보안 로그 등 요청 정보를 서비스 운영·보안을 위해 자체 정책에 따라 처리할 수 있습니다. 외부 링크를 열면 해당 사이트의 데이터 처리 정책이 적용됩니다.

Cloudflare 개인정보 안내 · GitHub 개인정보 안내

보관·삭제와 문의

보관함의 삭제 버튼으로 선택한 조합을 제거할 수 있습니다. “현재 조합 초기화”는 현재 조합을 기본값으로 바꾸는 기능이며 보관함 전체나 외부 서비스 자료를 삭제하는 기능은 아닙니다.

웹에서는 아래의 로컬 설정 삭제 버튼 또는 브라우저의 사이트 데이터 삭제 기능을 이용할 수 있습니다. 이 페이지의 버튼은 현재 접속한 주소의 이 브라우저 저장소만 지웁니다. 다른 JOHAP 주소·다른 브라우저·네이티브 앱의 자료는 별도로 남을 수 있습니다.

Android 앱의 기기 내 자료를 모두 지우려면 시스템 설정의 JOHAP 앱 정보에서 저장공간/데이터 삭제를 사용하거나 앱을 삭제합니다. iPhone·iPad에서는 앱을 완전히 삭제하면 앱의 기기 내 저장 자료도 제거됩니다. 홈 화면에서만 제거하거나 앱을 정리하는 동작은 앱의 완전 삭제와 다를 수 있습니다. 원본 앨범 사진, 이미 공유한 링크, 외부 서비스 로그나 문의 내용은 이 동작으로 지워지지 않습니다.

JOHAP 자체 계정은 없으므로 계정 탈퇴 절차는 없습니다. 개인정보 처리 문의는 문의 페이지를 이용해 주세요. 이 채널은 공개되므로 사진 원본·배틀태그·전화번호·주소·인증 정보 등 민감한 내용을 게시하지 마세요. GitHub 문의 게시물의 수정·삭제는 GitHub 기능과 정책을 따릅니다.
