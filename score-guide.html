JOHAP · SCORE METHODOLOGY

이 점수는 어떻게 계산되나요?

조건부 적합도 1~9점의 계산 순서, 다섯 항목의 가중치, 통계 추정과 불확실성 처리까지. 2026년 10월 1일 엔진 코드와 저장된 통계 자료를 기준으로 설명합니다.

01승리 확률이 아닌, 이 입력에서의 적합도

Johap의 점수는 현재 입력한 아군·상대 영웅, 맵, 구간과 통계 범위에 대한 조건부 평가입니다. 9점이 90% 승률을 뜻하거나, 그 영웅이 모든 상황에서 강하다는 뜻은 아닙니다.

5점은 중립 기준입니다. 등록된 근거가 없다는 이유만으로 유리함을 가산하지 않습니다. 근거가 있는 기본 능력·구간 프로필과 편집 규칙이 만든 점수이며, 실제 경기 결과로 보정한 승률 예측 모델은 아닙니다.

개인 후보와 팀 점수는 같은 다섯 항목과 같은 공개 척도를 사용하지만 항목의 대상을 다르게 계산합니다. 개인 후보의 맵 점수는 그 영웅 자신의 도구, 시너지 점수는 그 영웅이 직접 참여하는 동료 연결을 봅니다. 팀 점수는 입력한 팀 전체의 도구와 공백을 봅니다. 둘 다 같은 기본/궁극기/특전 구분과 구간 출처를 사용합니다. 기동성·유지력 등 그래프의 축과 개별 평가 항목은 0~10을 유지하며, 최종 적합도만 1~9입니다.

같은 입력의 원점수를 바꾸지 않은 채 후보를 더 추가하거나 제거해도 공개 점수는 같습니다. 후보 목록 안에서 최고·최저를 다시 1~9로 맞추는 방식이 아닙니다.

02다섯 항목을 합친 뒤, 고정된 척도로 변환

각 항목은 0~10점 · 중립 5 · 소수 한 자리
항목가중치계산 대상
상성30상대 도구에 대응하는지, 실제 상대 위협에 대한 공백이 있는지
맵20검토된 정확한 맵·구간·공수와 기본 도구의 연결; 미검토 구간은 임시 규칙
시너지25속도·진입·사거리·보호·이동 지원이 서로 연결되는지
제약 대응10관측된 상대 구성에서 가장 큰 편집 제약
통계15조건이 맞는 영웅 통계를 중립 쪽으로 축소한 보조 근거
항목 점수 pᵢ = 소수 한 자리 반올림(clip(해당 항목의 계산값, 0, 10)) rawScore = Σ(pᵢ × 가중치ᵢ) / Σ(사용한 가중치ᵢ) 공개 점수 = 소수 한 자리 반올림(clip(5 + (rawScore − 5) × 2.5, 1, 9))

clip(x,a,b)는 x를 a보다 작으면 a로, b보다 크면 b로 제한한다는 뜻입니다. 항목을 먼저 소수 한 자리로 반올림한 뒤 가중 평균을 구합니다. 가중 평균인 rawScore는 공개 변환 전에 다시 반올림하지 않습니다.

통계가 있는 경우

rawScore = (상성×30 + 맵×20 + 시너지×25 + 제약×10 + 통계×15) / 100

통계는 전체 가중치 중 15를 차지합니다. 전체·맵·티어 승률 세 개를 각각 15씩 더하지 않습니다.

통계가 없거나 점수에 쓸 수 없는 경우

rawScore = (상성×30 + 맵×20 + 시너지×25 + 제약×10) / 85

통계 항목과 가중치 15를 함께 제외합니다. 통계 값을 0점이나 중립 5점으로 채우지 않습니다.

원점수 rawScore변환 전 계산공개 점수
0~3.41 이하 → 하한으로 제한1.0

원식의 포화 경계는 3.4와 6.6입니다. 마지막 소수 한 자리 반올림 때문에 경계에 가까운 일부 값도 화면에 1.0 또는 9.0으로 보일 수 있습니다. 따라서 화면의 1·9만으로 원점수가 반드시 포화 경계 밖이라고 역산할 수 없습니다. 변환은 단조 증가하되 반올림과 상·하한에서 같은 점수가 나올 수 있습니다.

03기본 규칙과 검토된 조건을 연결하는 방법

먼저 기존 대응·연결 규칙을 계산하고, 확인된 기본 능력으로 설명할 수 있는 조건부 변화를 연결합니다. 검토된 맵 프로필이 있는 구간은 기존 맵 계산을 완전히 대체합니다. 수치는 편집한 휴리스틱 계수이며 실제 경기의 인과 효과나 승률 변화량이 아닙니다.

기본 능력 · 궁극기 · 선택 특전을 분리합니다. 상시 평가에는 근거가 있는 기본 능력만 넣습니다. 아군 견인·자기 이동을 적 끌어오기로 취급하지 않습니다. 궁극기와 선택 특전은 데이터에 남기되 기본 점수에 자동 가산하지 않습니다.

unknown은 확인된 부재가 아닙니다. 현재 프로필이 보류한 능력을 과거 태그로 다시 확정하지 않습니다. 해당 기제는 중립으로 남기고, 명시적 부재가 확인된 경우에만 그 부재를 사용하는 조건을 검토합니다. 이것이 영웅 전체 점수를 무조건 5로 만든다는 뜻은 아닙니다. 프로필 자체가 없는 영웅·구간의 기존 태그는 임시 근거라고 표시합니다.

contextEffects.delta는 해당 항목의 0~10 단위입니다. 승률 %p나 최종 1~9점의 직접 변화가 아닙니다. 예를 들어 통계를 포함할 때 시너지 항목의 +1은 가중 평균에 +0.25, 공개 변환 전 값에 +0.625를 더합니다. 반올림·상하한 때문에 실제 표시 차이는 달라질 수 있습니다.

상성·시너지·제약: 최종 항목 = 반올림₁(clip(기존 항목 + 중복을 제거한 새 변화, 0, 10)) 검토된 맵: 최종 항목 = 반올림₁(5 + 검토된 구간 변화 합) 각 항목의 표시 변화 = 기존 중립 이탈 + 새 변화 + 0~10 범위 조정 마지막 항목 반올림 때문에 변화 합과 표시값에 최대 0.05 차이가 날 수 있음

개인 조건부 평가의 변화 합은 맵 ±2, 다른 항목 ±2.5를 넘으면 각 변화를 같은 비율로 축소합니다. 이후 기존 항목과 합칠 때 속도·진입·사거리·보호 연결의 중복 가산을 없애고, 제약은 더 큰 위험 하나만 반영합니다. 모든 항목은 최종 0~10 범위를 지킵니다.

상성 · 가중치 30

대상원래 계산해석
개인 후보5 + 0.7×U − 0.9×L + BU: 후보가 상대 도구에 대응하는 상대 영웅 수. L: 상대가 후보 도구에 대응하는 상대 영웅 수. 수면→상대 정화 제약은 여기서 빼고 제약 항목에서만 계산합니다. B: 상대 돌격의 편집 대응 목록에서 후보가 1순위면 +1.2, 그 밖의 등록 순위면 +0.6, 미등록이면 0.
팀5 − 0.9×G + 0.6×AG: 실제 상대 영웅이 연결된 대응 공백의 개수. A: 아군이 보유한 대응 도구 항목의 개수. 단순히 개선할 여지가 있다는 이유만으로 공백으로 감점하지 않습니다.

같은 상대 한 명에 대한 대응 태그가 여러 개여도 그 상대에 대한 +0.7 또는 −0.9는 각각 한 번입니다. U와 L은 같은 상대에 대해 동시에 성립할 수 있습니다. 검토된 긴 시야 구간에서는 팀의 poke-no-dive 대응 공백 감점과 대응 보유 가산을 제외합니다. 다이브 도구만으로 긴 접근 거리가 해결된다고 보지 않습니다.

현재 직접 도구 대응 쌍: 다이브 → 포킹 / 방벽 파괴 → 방벽 / 진입 저지(anchor) → 다이브 정화 → 수면 / 측면 → 방벽 / 고지 접근(vertical) → 방벽

상대 조건에서 추가하는 기제

기제기본 변화와 성립 조건

치유 차단 기회후보의 기본 치유 차단이 있고 상대의 자기 회복·아군 치유가 확인되면 상성 +min(1.1, 0.4×대상 수). 상대 기본 정화가 있으면 ×0.5. 실제 적중과 정화 사용 창이 필요합니다.
제어로 상대 진입 대응후보의 기본 행동 제어와 상대의 기본 진입 도구가 확인되면 상성 +0.7. 도구의 범위·적중·후속은 관측하지 않습니다.
후보 진입의 제어 위험후보의 기본 진입과 상대의 기본 행동 제어가 확인되면 제약 −0.8을 검토합니다. 기존 제약보다 약하면 다시 감점하지 않습니다.

팀 평가는 같은 기제에 해당하는 개인 효과 중 절댓값이 가장 큰 한 건만 반영합니다. 서로 다른 팀원에게 같은 관계가 있다는 이유로 반복 가산하지 않습니다. 위 계수는 개인의 항목별 상한 조정 전 값입니다.

맵 · 정확한 맵·구간·공수를 연결

맵 ID·구간 ID·공격/수비/대칭이 모두 일치해야 검토 프로필을 사용합니다. 현재 159구간 중 24개에 부분 프로필이 있고, 135개는 미검토입니다. 18개 출처에서 확인한 시야·고지·엄폐·동선만 사용하며 빈 항목은 채우지 않습니다. 공격에 확인된 우회로를 수비의 안전한 접근로로 복사하지 않습니다.

서킷 2의 긴 시야와 3의 혼합 시야를 구분하고, 왕의 길 C는 마지막 구간이어도 고지 경합을 유지합니다. 아이헨 B의 계단과 할리우드 B의 승강기는 수직 이동기가 없어도 가능한 접근으로 기록합니다. 공격·수비라는 이름 자체에 고정 보너스는 없습니다.

맵 변화 합은 ±2로 제한 · 중립 5에서 시작 · 알려지지 않은 기능과 지형은 해당 기제 중립
확인된 구간 조건개인 후보의 맵 변화
긴 시야원거리 도구가 있으면 +1.3. 없고 중거리 도구가 있으면 −0.4. 근거리만 확인됐으면 단계적 엄폐가 있을 때 −0.5, 그렇지 않으면 −1.3.
짧은 시야근거리 도구 +0.9, 없으면 중거리 +0.3, 원거리만 확인되면 −0.5.
혼합 시야중거리 도구 +0.6. 없으면 원거리 +0.5. 근거리만 확인됐고 단계적 엄폐가 있으면 +0.5, 그 외 0. 사거리 도구 중 해당 분기 한 번만 사용합니다.

노출된 접근·출처의 조건부 조언실행 조건으로 표시합니다. 사거리·엄폐에서 계산한 노출 비용을 다시 감점하지 않으며, 출처 문장 자체에는 추가 점수를 붙이지 않습니다.

팀도 같은 구간 근거를 사용합니다. 사거리·수직 접근·측면 접근별로 확인된 개인 변화가 큰 순서의 최대 2명을 평균합니다. 미확인을 0으로 끼워 넣지 않고, 고지·측면 접근이 둘 다 양수면 큰 접근 기제 한 번만 유지합니다. 합계 ±2를 적용하고 중립 5에 더합니다. 이는 팀 전원의 이동 가능성이나 치유량을 뜻하지 않습니다.

검토 프로필이 있으면 기존 맵 가산·구간 계획 가중을 함께 더하지 않습니다. 추천·전술의 지형 조건도 같은 프로필을 우선해, 예전 “긴 시야” 태그가 다른 구간의 설명을 되돌리지 않게 합니다. 통계는 구간·공수별 자료가 없으므로 동일 맵·영웅·티어에서는 그대로 유지합니다.

미검토 구간에서만 사용하는 임시 맵 규칙
개인 후보는 자신의 도구, 팀은 입력된 인원의 도구를 계산합니다.
지형·조건개인 후보팀

요청 맵×티어에 직접 제공된 값이 있으면 그 한 건을 사용합니다. 직접 교차 자료가 없고 필요한 세 근거가 있으면 아래의 제한된 추정을 사용합니다.

W = clip(T + clip(M − O, −6, +6) × c, 0, 100) c = min(0.5, q_map, q_overall) T: 선택 티어의 전체 맵 승률 M: 전체 티어의 선택 맵 승률 O: 전체 티어의 전체 맵 승률 q: 각 원본 근거의 quality(0~1)

맵 보정은 최대 ±3%p입니다. M−O를 먼저 ±6%p로 제한하고 c를 최대 0.5로 제한하기 때문입니다. 이 W는 공개되지 않은 맵×티어의 추정 승률입니다. 해당 교차 범위에서 직접 관측된 승률로 표시하지 않습니다.

추정에는 같은 원본과 같은 큐·지역·플랫폼을 사용하고, 저장된 패치·시즌 메타데이터가 일치해야 합니다. 메타데이터가 모두 미공개인 경우에도 코드상 일치할 수 있으므로, 이것이 실제 집계 기간까지 검증됐다는 뜻은 아닙니다. 맵·전체 근거는 아래의 사용 가능 조건을 통과해야 하며, 최종 점수 사용 여부는 세 근거 모두를 다시 확인합니다.

quality: 공개되지 않은 표본 수를 만들어 내지 않기

q₀ = 표본 수 N을 알면 min(1, N / (N + 200)), 모르면 0.45 원본 집계일을 모르면 q₁ = min(q₀, 0.45), 알면 q₁ = q₀ 픽률 P를 알면 q₂ = q₁ × min(1, P / 3), 모르면 q₂ = q₁ 자료가 7일 넘었으면 q = clip(q₂ × 0.5, 0, 1), 아니면 q = clip(q₂, 0, 1)

P의 단위는 퍼센트 숫자입니다. 예를 들어 픽률 1%를 P=1로 넣습니다. 표본·집계일이 모두 미공개이고 픽률이 3% 이상인 새 자료의 q는 0.45입니다. 픽률 0.3%이면 0.45×0.1=0.045로 더 줄어듭니다.

추정 승률에서 통계 보조 점수까지

기본 신뢰 반영계수 R₀ = min(사용한 모든 근거의 q) 직접 원본: R = R₀ 맵×티어 추정: R = R₀ × 0.7, 신뢰도 낮음 선택 맵 자료 없이 같은 티어 전체 맵으로 대체: 맵을 요청했다면 R = R₀ × 0.8 선택 티어가 없어 전체 티어로 대체: R = R₀ × 0.6, 신뢰도 낮음 W_effective = 50 + (W − 50) × R 통계 보조 점수 S = 5 + clip((W_effective − 50) / 4, −D, +D) D = 신뢰도 높음 2.0 / 보통 1.75 / 낮음 1.25

W_effective는 불확실성을 중립 50 쪽으로 축소한 계산 내부의 보조값입니다. 실제 경기에서 측정한 새 승률이나 신뢰구간의 하한이 아닙니다. 최종 통계 항목 S도 다른 항목과 같이 소수 한 자리로 반올림한 뒤 가중치 15로 합칩니다.

신뢰도는 표본·집계일·자료 나이·픽률로 정합니다. 표본 또는 집계일 미공개, 7일 초과, 픽률 3% 미만이면 낮음입니다. 그 조건이 없고 표본≥1,000이면 높음, 표본≥200이면 보통, 나머지는 낮음입니다. 여러 근거를 쓸 때 가장 낮은 신뢰도를 사용하며 맵×티어 추정은 항상 낮음입니다.

대체값과 교차 추정값을 구분합니다. 맵×티어 추정에 필요한 자료가 부족하면 같은 티어 전체 맵 또는 전체 티어 자료를 보조 점수에 사용할 수 있습니다. 이때 화면에서 실제 적용 범위를 표시하고, compositeWinRate는 미확인으로 둡니다. 대체 승률을 요청 맵×티어의 승률로 주장하지 않습니다.

팀 통계의 축소

보유 비율 C = 통계 점수 사용 가능한 영웅 수 / 중복 제거한 입력 영웅 수 팀 통계 점수 = clip(5 + (사용 가능한 영웅 S의 단순 평균 − 5) × C, 3, 7) 사용 가능한 영웅이 한 명도 없으면 통계 점수 미반영

예를 들어 입력한 5명 중 3명만 통계가 있으면 평균의 중립 이탈을 3/5로 줄입니다. 모르는 두 명을 강한 영웅으로 채우지 않습니다. 이것도 팀 승리 확률이나 다섯 영웅 조합의 실측 시너지 통계는 아닙니다.

모드별 수치는 같은 출처의 맵별 승률을 같은 비중으로 평균한 비교용 값이고, 맵 의존도는 그 맵별 승률의 모집단 표준편차입니다. 둘 다 추천 점수에 추가 가산하지 않습니다. 경기 수로 가중한 모드 전체 승률과 다릅니다.

예시 B · 승률 55%의 신뢰도 축소
