JOHAP · SCORE METHODOLOGY

이 점수는 어떻게 계산되나요?

조건부 적합도 1~9점의 계산 순서, 다섯 항목의 가중치, 통계 추정과 불확실성 처리까지. 2026년 10월 1일 엔진 코드와 저장된 통계 자료를 기준으로 설명합니다.

기준일 2026-10-01개인 후보 평가 · 팀 평가원점수 0~10 → 공개 점수 1~9외부 연결 없이 읽을 수 있는 보고서
← 조합 분석점수의 의미가중 평균과 변환항목별 규칙통계 계산계산 예시한계와 검증 범위

01승리 확률이 아닌, 이 입력에서의 적합도

Johap의 점수는 현재 입력한 아군·상대 영웅, 맵, 구간과 통계 범위에 대한 조건부 평가입니다. 9점이 90% 승률을 뜻하거나, 그 영웅이 모든 상황에서 강하다는 뜻은 아닙니다.

5점은 중립 기준입니다. 등록된 근거가 없다는 이유만으로 유리함을 가산하지 않습니다. 도구 태그와 편집 규칙이 만든 점수이며, 실제 경기 결과로 보정한 승률 예측 모델은 아닙니다.

개인 후보와 팀 점수는 같은 다섯 항목과 같은 공개 척도를 사용하지만 항목의 대상을 다르게 계산합니다. 개인 후보의 맵 점수는 그 영웅 자신의 도구, 시너지 점수는 그 영웅이 직접 참여하는 동료 연결을 봅니다. 팀 점수는 입력한 팀 전체의 도구와 공백을 봅니다.

같은 입력의 원점수를 바꾸지 않은 채 후보를 더 추가하거나 제거해도 공개 점수는 같습니다. 후보 목록 안에서 최고·최저를 다시 1~9로 맞추는 방식이 아닙니다.

02다섯 항목을 합친 뒤, 고정된 척도로 변환

각 항목은 0~10점 · 중립 5 · 소수 한 자리
항목가중치계산 대상
상성30상대 도구에 대응하는지, 실제 상대 위협에 대한 공백이 있는지
맵20편집된 지형 분류와 선택 구간 계획에 영웅 도구가 맞는지
시너지25속도·진입·사거리·보호·이동 지원이 서로 연결되는지
제약 대응10관측된 상대 구성에서 가장 큰 편집 제약
통계15조건이 맞는 영웅 통계를 중립 쪽으로 축소한 보조 근거
항목 점수 pᵢ = 소수 한 자리 반올림(clip(해당 항목의 계산값, 0, 10)) rawScore = Σ(pᵢ × 가중치ᵢ) / Σ(사용한 가중치ᵢ) 공개 점수 = 소수 한 자리 반올림(clip(5 + (rawScore − 5) × 2.5, 1, 9))

clip(x,a,b)는 x를 a보다 작으면 a로, b보다 크면 b로 제한한다는 뜻입니다. 항목을 먼저 소수 한 자리로 반올림한 뒤 가중 평균을 구합니다. 가중 평균인 rawScore는 공개 변환 전에 다시 반올림하지 않습니다.

통계가 있는 경우

rawScore = (상성×30 + 맵×20 + 시너지×25 + 제약×10 + 통계×15) / 100

통계는 전체 가중치 중 15를 차지합니다. 전체·맵·티어 승률 세 개를 각각 15씩 더하지 않습니다.

통계가 없거나 점수에 쓸 수 없는 경우

rawScore = (상성×30 + 맵×20 + 시너지×25 + 제약×10) / 85

통계 항목과 가중치 15를 함께 제외합니다. 통계 값을 0점이나 중립 5점으로 채우지 않습니다.

원점수와 공개 점수의 대응

원점수 rawScore변환 전 계산공개 점수
0~3.41 이하 → 하한으로 제한1.0
4.05 + (4 − 5) × 2.52.5
4.65 + (4.6 − 5) × 2.54.0
5.0중립 유지5.0
5.45 + (5.4 − 5) × 2.56.0

6.6~109 이상 → 상한으로 제한9.0

원식의 포화 경계는 3.4와 6.6입니다. 마지막 소수 한 자리 반올림 때문에 경계에 가까운 일부 값도 화면에 1.0 또는 9.0으로 보일 수 있습니다. 따라서 화면의 1·9만으로 원점수가 반드시 포화 경계 밖이라고 역산할 수 없습니다. 변환은 단조 증가하되 반올림과 상·하한에서 같은 점수가 나올 수 있습니다.

03네 가지 규칙 항목의 원래 계산

아래 가산·감산을 중립 5에 적용한 뒤 각 항목을 0~10으로 제한하고 소수 한 자리로 반올림합니다. 숫자는 현재 편집 규칙의 계수이며, 실제 경기에서 추정한 인과 효과나 승률 변화량이 아닙니다.

상성 · 가중치 30

대상원래 계산해석
개인 후보5 + 0.7×U − 0.9×L + BU: 후보가 상대 도구에 대응하는 상대 영웅 수. L: 상대가 후보 도구에 대응하는 상대 영웅 수. B: 상대 돌격의 편집 대응 목록에서 후보가 1순위면 +1.2, 그 밖의 등록 순위면 +0.6, 미등록이면 0.
팀5 − 0.9×G + 0.6×AG: 실제 상대 영웅이 연결된 대응 공백의 개수. A: 아군이 보유한 대응 도구 항목의 개수. 단순히 개선할 여지가 있다는 이유만으로 공백으로 감점하지 않습니다.

같은 상대 한 명에 대한 대응 태그가 여러 개여도 그 상대에 대한 +0.7 또는 −0.9는 각각 한 번입니다. U와 L은 같은 상대에 대해 동시에 성립할 수 있습니다. 긴 시야 구간에서는 팀의 poke-no-dive 대응 보유 가산을 제외합니다.

현재 직접 도구 대응 쌍: 다이브 → 포킹 / 방벽 파괴 → 방벽 / 진입 저지(anchor) → 다이브 정화 → 수면 / 측면 → 방벽 / 고지 접근(vertical) → 방벽

맵 · 가중치 20

개인 후보는 자신의 도구, 팀은 입력된 인원의 도구를 계산합니다.
지형·조건개인 후보팀
긴 시야원거리 태그가 있으면 +2.0. 근접 태그가 있고 원거리 태그가 없으면 −1.5. 후보가 편집된 다이브 돌격이면 추가 −1.4.원거리 인원 r에 대해 +min(2, 0.7×r). 돌격이 다이브 돌격이면 −1.4. r=0이며 입력 인원≥3이면 −1.2.
고지 거점직접 고지 접근 태그가 있으면 +1.6. 없고 근접 태그가 있으면 −1.2. 이 두 조건에 해당하지 않는 비기동 돌격이면 −0.8. 원거리 태그가 있으면 별도로 +0.7.고지 접근 인원 m에 대해 +min(1.8, 0.6×m). 돌격이 편집된 기동 돌격 집합에 없으면 −0.8.
평지 거점근접 태그 또는 편집된 근접 돌격이면 +1.3.편집된 근접 돌격이면 +1.0.
좁은 러시 거점근접 태그 또는 근접 돌격이면 +1.8. 후보가 속도 지원 태그를 가지면 +1.0. 원거리 태그가 있고 근접 태그가 없으면 −0.8.근접 돌격이면 +1.0. 팀에 속도 지원과 느린 돌격 태그가 모두 있으면 추가 +1.0.
선택 구간의 계획 가중팀이 계획의 모든 요구 태그를 채우고, 후보 자신도 요구 태그 중 하나 이상을 제공하는 계획만 사용.팀이 계획의 모든 요구 태그를 채우는 계획을 사용.
맵 항목 = 5 + 위 지형 가산·감산 + clip(Σ 선택 구간의 계획 가중, −2, +2) 계획 가중: 유리 +1 / 불리 −1 / 보통 0 같은 계획 ID는 한 번만 사용. 요구 태그가 비어 있는 계획은 사용하지 않음.

다른 팀원의 원거리·기동 인원을 개인 후보 자신의 능력으로 더하지 않습니다. 다른 맵에 속한 구간 ID를 입력하면 구간 조건을 비웁니다. 지형 분류는 편집된 규칙이며, 현재 화면의 엄폐와 공격·수비 동선을 실시간으로 측정한 결과가 아닙니다.

현재 지형 분류: 서킷 로얄·아바나·정커타운은 긴 시야, 리장 타워 관제 센터 구간은 러시 거점, 등록된 혼합 맵 A거점은 고지·C화물은 평지입니다. 그 밖에는 일반 구간으로 취급합니다. 세부 경로와 최신 맵 개편을 모두 검증했다는 뜻은 아닙니다.

개인 후보의 시너지 · 가중치 25

후보가 참여하는 연결만 계산합니다. 예를 들어 다른 두 팀원이 이미 속도·근접 시너지를 갖고 있어도 관련 없는 후보에게 그대로 보너스를 주지 않습니다. 팀 공통의 역할 공백도 모든 후보의 개인 시너지에 복사하지 않습니다.

중립 5에 아래 조건을 적용 · “또는” 태그 중 하나 이상이면 해당 도구를 보유한 것으로 판정
연결조건과 증감
속도·근접 연결① 후보가 속도 지원이며 근접 동료≥2: +1.4. 그렇지 않으면 ② 동료 속도 지원이 있고 후보가 근접: +1.4. 이 둘에 해당하지 않으면 ③ 동료 속도 지원·근접 동료≥2·기동 가능한 지원 후보: +0.8. 이 세 분기는 한 번만 적용합니다.
후보가 직접 진입후보가 다이브 돌격 집합 또는 다이브 태그를 보유: 후속 기동 동료 n이 있으면 +min(1.5, 0.6×n). n=0이며 다른 동료≥2이면 −1.4.
동료가 직접 진입위 진입 후보 분기에 해당하지 않고 다이브 동료가 있을 때: 기동 후보 +1.2. 그렇지 않고 지원 후보가 원거리 조준·아군 순간이동·아군 위치 이동 도구 중 하나를 보유하면 +0.8. 이것도 아니며 근접 후보이면 −1.3. 세 분기는 한 번만 적용합니다.
원거리 연결후보가 원거리이며, 동료도 한 명 이상 원거리 태그를 보유: +1.2.
후보와 원거리 동료의 거리 분리후보가 근접이고 기동 도구가 없으며 원거리 동료≥2: −1.2.
후보와 근접 본대의 거리 분리후보가 원거리·비근접이고 동료 속도 지원이 있으며 근접 동료≥2: −1.1.
보호·치유 연결후보가 진입 저지·방벽·투사체 흡수 중 하나를 제공하고 지원 동료가 있으면 +0.5. 그렇지 않고 후보가 지원이며 등록 태그가 있고 보호 동료가 있으면 +0.5. 한 번만 적용합니다.
이동 지원·강습 형태후보가 이동 지원이고 다른 동료가 강습 형태이거나, 그 반대이면 +1.0.

기동 태그 집합은 다이브·측면·비행·고지 접근·자기 속도·점멸·자기 위치 이동·이탈입니다. 실제로 도착하는 시각, 치유 시야와 자원이 맞는지는 관측하지 않습니다. 표에서 명시한 분기 외에는 여러 조건의 가산·감산이 동시에 적용될 수 있습니다.

제약 대응 · 가중치 10

제약 항목 = 5 − max(적용되는 편집 제약) 편집 대응 목록 1순위 상대: 2.5 / 그 밖의 등록 상대: 1.2 윈스턴 후보에 자리야·바스티온·리퍼·젠야타가 모두 상대편: 4.0 수면 보유 영웅에 상대 정화 태그: 1.2

여러 제약이 있어도 합산하지 않고 가장 큰 감점 하나를 사용합니다. 개인 후보는 그 영웅 한 명의 제약만, 팀은 모든 입력 영웅의 제약 중 가장 큰 값을 봅니다. 미등록 카운터는 유리함으로 바꾸지 않으며, 등록된 제약이 없으면 중립 5입니다.

04승률 통계는 한 번만, 불확실성을 줄여 반영

통계는 같은 큐·지역·플랫폼·역할 고정 조건에서 찾습니다. 계산에 쓰는 원본의 우선순위는 Blizzard → OWTics → OW Hero Stats이며, 한 계산에서 원본을 섞지 않습니다. 현재 저장된 스냅샷의 원본은 Blizzard입니다.

별도 비교 자료측정 범위함께 더하는가?
전체 승률전체 맵 × 전체 티어비교용 근거입니다. 세 승률을 점수 항목 세 개로 만들거나 평균해 중복 가산하지 않습니다.
맵별 승률선택 맵 × 전체 티어
티어별 승률전체 맵 × 선택 티어

요청 맵×티어에 직접 제공된 값이 있으면 그 한 건을 사용합니다. 직접 교차 자료가 없고 필요한 세 근거가 있으면 아래의 제한된 추정을 사용합니다.

W = clip(T + clip(M − O, −6, +6) × c, 0, 100) c = min(0.5, q_map, q_overall) T: 선택 티어의 전체 맵 승률 M: 전체 티어의 선택 맵 승률 O: 전체 티어의 전체 맵 승률 q: 각 원본 근거의 quality(0~1)

맵 보정은 최대 ±3%p입니다. M−O를 먼저 ±6%p로 제한하고 c를 최대 0.5로 제한하기 때문입니다. 이 W는 공개되지 않은 맵×티어의 추정 승률입니다. 해당 교차 범위에서 직접 관측된 승률로 표시하지 않습니다.

추정에는 같은 원본과 같은 큐·지역·플랫폼을 사용하고, 저장된 패치·시즌 메타데이터가 일치해야 합니다. 메타데이터가 모두 미공개인 경우에도 코드상 일치할 수 있으므로, 이것이 실제 집계 기간까지 검증됐다는 뜻은 아닙니다. 맵·전체 근거는 아래의 사용 가능 조건을 통과해야 하며, 최종 점수 사용 여부는 세 근거 모두를 다시 확인합니다.

quality: 공개되지 않은 표본 수를 만들어 내지 않기

q₀ = 표본 수 N을 알면 min(1, N / (N + 200)), 모르면 0.45 원본 집계일을 모르면 q₁ = min(q₀, 0.45), 알면 q₁ = q₀ 픽률 P를 알면 q₂ = q₁ × min(1, P / 3), 모르면 q₂ = q₁ 자료가 7일 넘었으면 q = clip(q₂ × 0.5, 0, 1), 아니면 q = clip(q₂, 0, 1)

P의 단위는 퍼센트 숫자입니다. 예를 들어 픽률 1%를 P=1로 넣습니다. 표본·집계일이 모두 미공개이고 픽률이 3% 이상인 새 자료의 q는 0.45입니다. 픽률 0.3%이면 0.45×0.1=0.045로 더 줄어듭니다.

추정 승률에서 통계 보조 점수까지

기본 신뢰 반영계수 R₀ = min(사용한 모든 근거의 q) 직접 원본: R = R₀ 맵×티어 추정: R = R₀ × 0.7, 신뢰도 낮음 선택 맵 자료 없이 같은 티어 전체 맵으로 대체: 맵을 요청했다면 R = R₀ × 0.8 선택 티어가 없어 전체 티어로 대체: R = R₀ × 0.6, 신뢰도 낮음 W_effective = 50 + (W − 50) × R 통계 보조 점수 S = 5 + clip((W_effective − 50) / 4, −D, +D) D = 신뢰도 높음 2.0 / 보통 1.75 / 낮음 1.25

W_effective는 불확실성을 중립 50 쪽으로 축소한 계산 내부의 보조값입니다. 실제 경기에서 측정한 새 승률이나 신뢰구간의 하한이 아닙니다. 최종 통계 항목 S도 다른 항목과 같이 소수 한 자리로 반올림한 뒤 가중치 15로 합칩니다.

신뢰도는 표본·집계일·자료 나이·픽률로 정합니다. 표본 또는 집계일 미공개, 7일 초과, 픽률 3% 미만이면 낮음입니다. 그 조건이 없고 표본≥1,000이면 높음, 표본≥200이면 보통, 나머지는 낮음입니다. 여러 근거를 쓸 때 가장 낮은 신뢰도를 사용하며 맵×티어 추정은 항상 낮음입니다.

대체값과 교차 추정값을 구분합니다. 맵×티어 추정에 필요한 자료가 부족하면 같은 티어 전체 맵 또는 전체 티어 자료를 보조 점수에 사용할 수 있습니다. 이때 화면에서 실제 적용 범위를 표시하고, compositeWinRate는 미확인으로 둡니다. 대체 승률을 요청 맵×티어의 승률로 주장하지 않습니다.

팀 통계의 축소

보유 비율 C = 통계 점수 사용 가능한 영웅 수 / 중복 제거한 입력 영웅 수 팀 통계 점수 = clip(5 + (사용 가능한 영웅 S의 단순 평균 − 5) × C, 3, 7) 사용 가능한 영웅이 한 명도 없으면 통계 점수 미반영

예를 들어 입력한 5명 중 3명만 통계가 있으면 평균의 중립 이탈을 3/5로 줄입니다. 모르는 두 명을 강한 영웅으로 채우지 않습니다. 이것도 팀 승리 확률이나 다섯 영웅 조합의 실측 시너지 통계는 아닙니다.

모드별 수치는 같은 출처의 맵별 승률을 같은 비중으로 평균한 비교용 값이고, 맵 의존도는 그 맵별 승률의 모집단 표준편차입니다. 둘 다 추천 점수에 추가 가산하지 않습니다. 경기 수로 가중한 모드 전체 승률과 다릅니다.

예시 B · 승률 55%의 신뢰도 축소

가정직접 승률 55%, 픽률 10%, 새 수집 시각. 표본 수·원본 집계일은 미공개.

  1. q=0.45, 직접 원본이므로 R=0.45.
  2. W_effective = 50 + (55−50)×0.45 = 52.25.
  3. S = 5 + (52.25−50)/4 = 5.5625 → 통계 항목 5.6점.
  4. 다른 네 항목이 모두 5라면 rawScore=(5×85+5.6×15)/100=5.09 → 공개 5.2점.

55%를 곧바로 5.5점으로 바꾸거나 공개 점수에 직접 더하는 계산이 아닙니다.

예시 C · 공개되지 않은 맵×티어 교차 범위

가정T=54%, M=58%, O=52%. 세 근거 모두 픽률 10%, 새 수집 시각, 표본·집계일 미공개이며 같은 원본·패치·시즌 메타데이터.

  1. 각 q=0.45, c=min(0.5,0.45,0.45)=0.45.
  2. W = 54 + clip(58−52,−6,+6)×0.45 = 56.7% 추정.
  3. R = min(0.45,0.45,0.45)×0.7 = 0.315.
  4. W_effective = 50 + (56.7−50)×0.315 = 52.1105.
  5. S = 5 + 2.1105/4 = 5.527625 → 통계 항목 5.5점.
  6. 다른 네 항목이 모두 5라면 rawScore=5.075 → 공개 5.2점.

T·M·O를 모두 개별 가산하지 않습니다. W 한 개를 만들고, 추정의 불확실성을 다시 축소합니다.

예시 D · 세 명의 팀 통계만 있는 경우

5명 중 통계 사용 가능한 3명의 보조 점수가 6.0·5.6·4.4라면 평균은 5.333333…입니다.

팀 통계 = 5 + (5.333333…−5)×(3/5) = 5.2점. 나머지 네 항목이 모두 5라면 rawScore=5.03 → 공개 5.1점.

06측정 한계와 이 보고서의 확인 범위

  • 현재 저장된 통계: 40개 범위·2,120개 영웅 수치 레코드입니다. 40개 범위 모두 표본 수와 원본 집계일은 미공개로 저장되어 있습니다. 2,120은 경기 표본 수가 아닙니다.
  • 실제 표본과 패치: 신뢰구간, 경기 수에 따른 표본 가중치, 정확한 집계 기간과 해당 패치를 확인할 수 없습니다. 수집 날짜를 원본 집계 날짜로 쓰지 않습니다.
  • 그랜드마스터·챔피언: 통합 제공된 원본 범위는 합산으로 처리합니다. 챔피언 단독 실측값으로 나누지 않습니다.
  • 태그와 편집 규칙: 현재 등록된 대응 관계는 완전한 카운터 목록이 아닙니다. 치유 시야·사거리·쿨타임·궁극기·플레이어 숙련도·실시간 위치를 점수 공식이 직접 측정하지 않습니다.
  • 미완성 입력: 중복 영웅은 제거하고 빈 자리는 채우지 않습니다. 미등록 개인 후보의 네 규칙 항목은 중립 5로 유지하며 통계를 추가하지 않습니다. 5대5 미완성, 미등록 영웅과 지형 근거 부족은 불확실성 설명에 표시합니다.
  • 코드 검증: 가중 평균·포화 경계·통계 유무·quality 축소·교차 추정 예시를 현재 엔진 함수로 실행해 확인했습니다. 이 검증은 계산 구현의 일치를 확인한 것이며 추천이 실제 경기에서 승률을 높인다는 성능 검증은 아닙니다.
