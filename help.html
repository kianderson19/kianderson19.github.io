JOHAP / HELP

사용 방법

내 역할부터 정하고, 점수보다 이유를 확인하세요.

1. 내 포지션과 전장 선택

분석 화면 위의 돌격·공격·지원 중 내 포지션을 고릅니다. 해당 역할의 우리 팀 영웅을 기준으로 추천을 볼 수 있습니다. 맵·공격/수비·구역도 현재 경기와 맞춰 주세요. 전장이 달라지면 엄폐, 시야, 고지 접근성이 달라져 추천의 기준도 달라집니다.

2. 양 팀 조합 입력

영웅 오른쪽의 변경 버튼을 누르면 같은 역할의 영웅 목록이 열립니다. 우리 팀과 상대 팀의 다섯 자리를 채워 주세요. 상대 영웅을 선택하면 같은 역할에서 대응할 영웅을 확인할 수 있습니다. 팀을 반대로 입력했다면 ‘팀 바꾸기’를 사용합니다.

3. 점수판 스크린샷 불러오기

게임 점수판에서 양 팀 초상화가 크게 보이는 화면을 저장해 불러오거나 붙여 넣습니다. 전체 화면이 지나치게 작거나 초상화가 가려졌다면 미확인으로 표시될 수 있습니다. 인식 목록에서 직접 영웅을 수정하고 ‘이 조합으로 넣기’를 눌러 반영합니다. 영웅과 맵은 확인하기 전까지 현재 조합을 바꾸지 않습니다.

양 팀에 같은 영웅이 있어도 각각 읽습니다. 물음표·가려진 초상화·비슷한 후보는 추측해서 확정하지 않습니다. 표시된 백분율은 이미지 일치 정도를 나타내며, 정확도 보장이나 경기 승리 확률이 아닙니다.

4. 추천과 교체

조합 추천은 우리 팀이 필요로 하는 도구를, 상대 카운터는 상대가 가진 위협에 대응하는 도구를 살펴봅니다. 추천 이유를 펼친 뒤 교체할 수 있습니다. 추천이 내 숙련도와 맞지 않으면 ‘영웅 풀 설정’으로 실제 사용할 수 있는 영웅을 한정해 보세요.

5. 저장·공유·복원

현재 조합과 전장 설정은 이 브라우저에 자동 저장됩니다. 새로고침해도 같은 상태에서 이어갈 수 있습니다. ‘되돌리기’는 최근 변경을 복원하고 ‘초기화’는 기본 조합으로 돌아갑니다. 공유 링크에는 양 팀 영웅과 맵·구역 정보가 담깁니다. 스크린샷이나 플레이어 이름은 포함하지 않습니다.

데스크톱에서 사용하기

다운로드 페이지에서 프로토타입을 받습니다. 경기 창을 선택하고 내 플레이어 이름이나 내 슬롯을 설정한 다음 캡처를 시작합니다. 점수판을 표시하면 읽을 수 있는 조합이 갱신됩니다. 가려진 영웅과 화면에서 확인되지 않은 구역은 미확인 상태를 유지하며 직접 선택할 수 있습니다.

처음에는 테두리 없는 창 모드 또는 창 모드에서 테스트해 주세요. 일반 표시 모드는 게임의 마우스 입력을 통과시키고, 편집 모드에서만 오버레이를 조작합니다. 전체화면 지원 및 Windows 실전 게임 호환성은 프로토타입 검증 단계입니다.

데스크톱 단축키와 종료

Ctrl + Alt + O는 오버레이 표시, Ctrl + Alt + I는 오버레이 조작 모드, Ctrl + Alt + S는 한 번 캡처, Ctrl + Alt + J는 메인 앱 열기입니다. 다른 앱이 단축키를 사용 중이면 앱의 버튼이나 트레이 메뉴를 사용합니다. macOS 미리보기에서는 Ctrl 대신 Command를 사용합니다.

메인 창의 닫기 버튼은 트레이로 숨깁니다. 완전히 종료하려면 트레이 메뉴의 종료를 누르세요. 잠금·절전 중에는 캡처가 중단되며 자동으로 다시 시작하지 않습니다. 캡처 대상에 개인 대화나 다른 프로그램이 포함되지 않도록 게임 창을 선택하세요.

오류가 발생하면

인식이 오래 걸리면 취소하고 점수판이 더 선명한 이미지로 다시 시도합니다. 맵 인식이 실패해도 영웅 결과는 따로 확인할 수 있습니다. 문의 시 앱 버전, 화면 해상도, 경기 모드와 재현 방법을 알려 주세요. 계정 비밀번호·인증 코드·개인정보가 포함된 캡처는 공개 문의에 올리지 마세요.
