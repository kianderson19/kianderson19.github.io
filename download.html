내 역할·전장·양 팀 조합을 한 화면에서.

Windows 오버워치 2용 프로토타입입니다. 정식 승인·실전 호환성 검증을 마친 제품은 아닙니다.

이 프로토타입에서 할 수 있는 일

  • 내 플레이어 이름 또는 슬롯을 기준으로 내 영웅·포지션을 설정하고 확인합니다.
  • 점수판에서 읽을 수 있는 맵·양 팀 조합을 갱신합니다. 구역은 읽은 근거가 있을 때 반영하고, 확인되지 않으면 직접 고릅니다.
  • 내 포지션 안에서 맵·구역·양 팀 조합을 반영한 추천을 다시 계산합니다.
  • 작은 오버레이에서 추천을 보고, 단축키로 표시·편집 상태를 바꿉니다.

처음 실행할 때

  1. ZIP을 받은 경우 압축을 풀고 Johap.exe를 실행합니다. 설치 파일은 안내에 따라 설치합니다.
  2. 오버워치는 테두리 없는 창 모드로 설정하고 앱에서 캡처할 창을 직접 선택합니다.
  3. 내 이름 또는 내 슬롯을 정하고 캡처를 시작합니다. 점수판을 열어 영웅과 맵을 확인합니다.
  4. 미확인·오래된 값은 직접 교정합니다. 기능을 확인하려면 앱의 데모 시나리오도 사용할 수 있습니다.

검증 상태와 한계

제공한 실제 스크린샷 두 장에서는 첫 이미지의 10명, 두 번째 이미지의 보이는 9명을 맞혔고 가려진 한 칸은 미확인으로 남겼습니다. 이 결과는 모든 해상도·게임 버전의 정확도를 보장하지 않습니다. Windows 게임 캡처, 입력 충돌, DPI와 전체화면 호환성은 실제 게임 PC에서 추가 확인이 필요합니다.

무료 프로토타입 빌드는 디지털 서명이 없습니다. 운영체제가 출처 확인 경고를 표시할 수 있습니다. 다운로드 출처와 SHA-256을 확인하고 실행 여부를 직접 판단하세요. Johap은 해당 경고나 보안 설정을 자동으로 해제하지 않습니다.

무료로 사용할 수 있나요?

이 프로토타입은 무료로 다운로드할 수 있습니다. Electron 자체에 라이선스 요금은 없습니다. 디지털 서명과 맞춤 도메인은 별도 선택 비용이며, 기본 다운로드·웹 분석에 결제가 필요하지 않습니다. 웹 광고와 데스크톱 앱은 별도입니다.
